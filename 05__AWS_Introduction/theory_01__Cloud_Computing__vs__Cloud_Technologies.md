### Облачные вычисления и облачные технологии


В литературе, блогосфере и обиходе эти понятия часто используют как синонимы.

Тем не менее:

* **Облачные вычисления** (`Cloud Computing`) — модель предоставления вычислительных ресурсов через сеть.

* **Облачные технологии** (`Cloud Technologies`) — то, что делает возможным существование облачных сервисов.


Таким образом, **облачные вычисления** — это один из вариантов реализации **облачных технологий**.  

---


### По уровню абстракции предоставляемого ресурса облачные сервисы делятся на:

#### 1. IaaS (`Infrastructure as a Service`) — инфраструктура как услуга ("айас")

**Провайдер**: 
- предоставляет базовые вычислительные ресурсы (*"голое железо"*): 
  - виртуальные машины, 
  - хранилища, 
  - сети. 
  
**Пользователь**:
- сам устанавливает на них ОС, ПО, управляет настройками (*"одевает это железо по своему усмотрению"*)

**Примеры**: 
- Amazon EC2, 
- Google Compute Engine, 
- Microsoft Azure VM

#### 2. PaaS (`Platform as a Service`) — платформа как услуга ("пас")

**Провайдер**:  
- предоставляет готовую среду разработки/выполнения приложений 
  - ОС, 
  - СУБД, 
  - среда выполнения, 
  - инструменты)
  
**Пользователь**: 
  - занимается только своим приложением и данными.

**Примеры**:  
    Google App Engine, Microsoft Azure App Service.

#### 3. SaaS (Software as a Service) — программное обеспечение как услуга ("сас")

**Провайдер**:  
- предоставляет готовое приложение, доступное через браузер/клиент

**Пользователь**:  
- вообще не заботится об инфраструктуре и платформе.

**Примеры**:   
- Google Workspace, 
- Microsoft 365, 
- Dropbox.

---

> Надо отметить, что это довольно грубые градации — некоторые сервисы сочетают черты нескольких моделей одновременно,   
> и однозначно отнести их к одной категории не всегда возможно.  
> Например, хорошо известный нам сервис Atlas MongoDB можно считать примером PaaS.  
> Но точнее отнести его к DBaaS (Database as a Service).
> 
> Дополнительные (производные) модели:
> 
> - **DaaS (Desktop as a Service)** — виртуальные рабочие столы «по требованию» (VDI в облаке).
> - **STaaS (Storage as a Service)** — облачное хранилище данных как отдельная услуга (Dropbox, Google Drive, Amazon S3 в чистом виде).
> - **DBaaS (Database as a Service)** — управляемые базы данных (Amazon RDS, Google Cloud SQL).
> - **FaaS (Function as a Service) / serverless** — выполнение отдельных функций без управления серверами вообще (AWS Lambda, Azure Functions, Google Cloud Functions).
> - **CaaS (Container as a Service)** — управление контейнерами и оркестрацией (Google Kubernetes Engine, Amazon ECS).
> - **MBaaS (Mobile Backend as a Service)** — готовый бэкенд для мобильных приложений (Firebase).
> - **XaaS / EaaS (Anything/Everything as a Service)** — обобщающее понятие для любых сервисов «по требованию».
