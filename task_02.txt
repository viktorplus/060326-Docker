Создание Dockerfile с Bash-скриптом с сохранением данных

1. Создайте Dockerfile, который будет базироваться на образе Debian Slim (debian:bookworm-slim)

2. Установите необходимый пакет curl

3. Создайте Bash-скрипт fetch_data.sh (например, покажите значение переменной URL_ENV)
   и добавьте этот скрипт в контейнер.

4. Определите рабочую директорию.

5. Настройте переменные окружения (например, переменная URL_ENV со значением "https://httpbin.org/json")

6. Укажите команду для запуска Bash-скрипта.

7. Определите точку монтирования для хранения скачанных данных.

8. Установите пользователя new_user для выполнения команд.

9. Создайте файл Dockerfile

10. Выполните сборку Docker-образа с помощью команды docker build -t fetch-data-image .

11. Запустите контейнер с помощью команды docker run --rm -v $(pwd)/data:/data fetch-data-image.
    - если локальной папки data нет, то она будет создана автоматически;
    - но лучше создать её явно: mkdir $(pwd)/data.



Результат: в окне терминала должно появиться примерно следующее:

Your URL: https://httpbin.org/json
