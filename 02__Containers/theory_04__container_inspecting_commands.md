### Команды инспектирования контейнеров

Здесь `<CONTAINER>` — имя или ID контейнера.

| Команда          | Обязательное  | Опциональное   | Краткое описание                                                               |
| ---------------- | ------------- | -------------- | ------------------------------------------------------------------------------ |
| `docker ps`      | —             | `[OPTIONS]`    | Показывает **запущенные** контейнеры                                           |
| `docker ps -a`   | —             | `[OPTIONS]`    | Показывает **все** контейнеры, включая остановленные                           |
| `docker logs`    | `<CONTAINER>` | `[OPTIONS]`    | Показывает логи контейнера                                                     |
| `docker logs -f` | `<CONTAINER>` | `[OPTIONS]`    | Показывает логи и **следит за новыми сообщениями** в реальном времени          |
| `docker top`     | `<CONTAINER>` | `[ps OPTIONS]` | Показывает процессы, запущенные внутри контейнера                              |
| `docker diff`    | `<CONTAINER>` | —              | Показывает изменения файловой системы контейнера относительно исходного образа |
| `docker inspect` | `<CONTAINER>` | `[OPTIONS]`    | Показывает подробную информацию о контейнере в формате JSON                    |
