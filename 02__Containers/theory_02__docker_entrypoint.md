### Что такое ENTRYPOINT?

`ENTRYPOINT` в Docker — это команда, которая задаётся как основной исполняемый процесс контейнера.


#### `Dockerfile`

```Dockerfile
FROM ubuntu

ENTRYPOINT ["sleep", "infinity"]
#ENTRYPOINT ["tail", "-f", "/dev/null"]
```

#### `docker run`

```bush
docker run ubuntu tail -f /dev/null
```

**ВАЖНО**: без указания команды контейнер (как правило) сразу же завершит свою работу.  
Поэтому, если хотим, чтобы контейнер оставался работающим:
* либо запускаем процесс (как выше)
* либо запускаем контейнер в интерактивном режиме
  ```
  docker run -it ubuntu bash
  ```

  Остановленный контейнер также можно запустить в интерактивном режиме, но с другим флагом:
  ```
  docker start -ai my_container
  ```
  (`bash` повторно указывать не нужно, если контейнер был создан с этой командой)
