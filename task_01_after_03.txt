1. Создать директорию для проекта и перейти в нее.

2. Создать файл index.html с содержимым.

3. Создать файл Dockerfile
    - на основе nginx:alpine
    - скопировать файл index.html в контейнер по адресу /usr/share/nginx/html/index.html
    (по умолчанию nginx доступен на 80-м порту)

4. Собрать image.

5. Запустить контейнер:
   - пробросить порт 8080 хоста на порт 80 контейнера.

6. Перейти в браузере по адресу http://localhost:8080 и увидеть сообщение из вашего index.html.
