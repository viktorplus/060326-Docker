1. Изменить файл fetch_data.sh
    - теперь он должен скачать данные с ресурса, указанного в переменной окружения URL_ENV
      curl "$URL_ENV" -o /data/info.json

2. Соберите образ с учётом изменений: docker build -t fetch-data-image .

3. Запустите контейнер с помощью команды docker run --rm -v $(pwd)/data:/data fetch-data-image.
    - если локальной папки data нет, то она будет создана автоматически;
    - но лучше создать её явно: mkdir $(pwd)/data.


Результат:

Скрипт fetch_data.sh будет выполнен в контейнере.
Данные будут скачаны с указанного API и сохранены в файл data/info.json на вашем локальном компьютере.
