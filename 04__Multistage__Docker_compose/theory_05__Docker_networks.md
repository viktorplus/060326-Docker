### Networks (сети)

Сеть Docker — виртуальная сеть, которая позволяет контейнерам обмениваться данными.

Основные типы сетей:

| Тип       | Назначение                                                                     |
| --------- | ------------------------------------------------------------------------------ |
| `bridge`  | стандартная сеть для контейнеров на одном Docker-хосте                         |
| `host`    | контейнер использует сетевой стек хоста, отдельной Docker-сети практически нет |
| `none`    | контейнер вообще не имеет сетевого подключения                                 |
| `overlay` | сеть между Docker-хостами, используется прежде всего в Swarm                   |

Для обычного Compose наиболее важен `bridge`.  
Compose обычно создаёт собственную bridge-сеть проекта, например:

```text
myproject_default
```

и подключает к ней сервисы. Поэтому контейнеры могут обращаться друг к другу по имени сервиса:

```text
web → db:5432
```

При этом `ports` для связи контейнеров между собой не нужен.


### Основные команды

| Команда                                       | Назначение                  |
| --------------------------------------------- | --------------------------- |
| `docker network ls`                           | Показать все Docker-сети    |
| `docker network inspect NAME`                 | Показать подробности сети   |
| `docker network create NAME`                  | Создать сеть                |
| `docker network rm NAME`                      | Удалить сеть                |
| `docker network prune`                        | Удалить неиспользуемые сети |
| `docker network connect NETWORK CONTAINER`    | Подключить контейнер к сети |
| `docker network disconnect NETWORK CONTAINER` | Отключить контейнер от сети |
